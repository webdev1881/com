# 📊 Импорт планов из Excel файла

## 🎯 Обзор функциональности

Компонент **Plans** теперь поддерживает загрузку планов из Excel файлов, что значительно упрощает массовое редактирование целевых показателей.

## 📥 Новые возможности

### 1. **Скачать шаблон Excel**
- **Кнопка:** "📥 Шаблон Excel"
- **Действие:** Генерирует и скачивает готовый шаблон Excel файла
- **Файл:** `Шаблон_планов_SMK.xlsx`

### 2. **Загрузить данные из Excel**
- **Кнопка:** "📤 Завантажити Excel" 
- **Форматы:** `.xlsx`, `.xls`
- **Действие:** Импортирует данные из Excel в компонент

## 🔄 Процесс импорта

### **Этапы обработки:**

1. **📁 Чтение файла** (20%) - Загрузка и проверка формата
2. **🔍 Парсинг данных** (40%) - Извлечение данных из листов
3. **✅ Валидация** (80%) - Проверка корректности данных
4. **💾 Применение** (100%) - Обновление интерфейса

### **Индикатор прогресса:**
- Визуальный прогресс-бар с анимацией
- Отображение текущего этапа
- Автоматическое закрытие при завершении

---

## ⚠️ Требования к данным

### **Обязательные листы:**
- ✅ **"Настройки показателей"** - конфигурация KPI
- ✅ **"Цели по магазинам"** - целевые значения

### **Формат значений:**
- **Ключи показателей:** строка (латиница, без пробелов)
- **Максимальные баллы:** число (1-200)
- **Тип показателя:** `positive` или `negative`
- **Целевые значения:** число (0.0-1.0, десятичные дроби)

### **Валидация:**
- Проверка структуры файла
- Контроль диапазонов значений
- Проверка типов данных
- Уведомления об ошибках

## 🚀 Пошаговая инструкция

### **1. Подготовка Excel файла:**

1. **Скачайте шаблон:**
   ```
   Планы → "📥 Шаблон Excel" → Сохранить файл
   ```

2. **Заполните данные:**
   - Откройте `Шаблон_планов_SMK.xlsx`
   - Отредактируйте лист "Настройки показателей"
   - Обновите лист "Цели по магазинам"
   - Сохраните файл

### **2. Импорт данных:**

1. **Загрузите файл:**
   ```
   Планы → "📤 Завантажити Excel" → Выбрать файл
   ```

2. **Следите за прогрессом:**
   - Дождитесь завершения обработки
   - Проверьте уведомления
   - При ошибках изучите сообщения

3. **Проверьте результат:**
   - Данные автоматически применяются
   - Интерфейс обновляется
   - Изменения отмечаются как несохраненные

### **3. Сохранение:**

```
"Зберегти" → Данные сохраняются в localStorage
```

## 🛠️ Технические детали

### **Используемые библиотеки:**
- **SheetJS (xlsx@0.18.5)** - парсинг Excel файлов

### **Поддерживаемые форматы:**
- ✅ `.xlsx` (Excel 2007+)

### **Ограничения:**
- **Размер файла:** до 10 МБ
- **Количество магазинов:** без ограничений
- **Количество показателей:** до 50

## 🔧 Устранение проблем

### **Частые ошибки:**

#### **"Неподдерживаемый формат файла"**
**Решение:** Используйте только .xlsx или .xls файлы

#### **"Не найдены настройки показателей"**
**Решение:** 
- Проверьте название листа: "Настройки показателей"
- Убедитесь в наличии заголовков в первой строке

#### **"Некорректное значение для магазина X"**
**Решение:**
- Значения должны быть от 0.0 до 1.0
- Используйте десятичную точку (0.015, не 0,015)

#### **"Ошибки валидации"**
**Решение:**
- Проверьте все обязательные поля
- Убедитесь в корректности типов данных
- Скачайте свежий шаблон

### **Отладка:**

1. **Откройте консоль браузера** (F12)
2. **Изучите сообщения** об ошибках
3. **Проверьте структуру** Excel файла
4. **Сравните с шаблоном**

```
1. Скачать шаблон с текущими данными

```
