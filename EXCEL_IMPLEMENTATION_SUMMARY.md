## 🔧 Техническая реализация

### **Импорт Excel файла:**
```javascript
import * as XLSX from 'xlsx'

// Чтение файла
const arrayBuffer = await file.arrayBuffer()
const workbook = XLSX.read(arrayBuffer, { type: 'array' })

// Парсинг листов
const settingsSheet = workbook.Sheets['Настройки показателей']
const targetsSheet = workbook.Sheets['Цели по магазинам']
```

### **Генерация шаблона:**
```javascript
// Создание workbook
const workbook = XLSX.utils.book_new()

// Добавление листов
XLSX.utils.book_append_sheet(workbook, settingsSheet, 'Настройки показателей')
XLSX.utils.book_append_sheet(workbook, targetsSheet, 'Цели по магазинам')

// Скачивание
XLSX.writeFile(workbook, 'Шаблон_планов_SMK.xlsx')
```

### **Валидация данных:**
- Проверка структуры файла (наличие обязательных листов)
- Контроль диапазонов значений (0.0-1.0)
- Проверка типов данных
- Валидация обязательных полей

## 🔄 Workflow использования

### **Для администратора:**
1. Скачать шаблон → Массово отредактировать → Загрузить
2. Распространить шаблон среди менеджеров
3. Собрать заполненные файлы и импортировать

### **Для менеджера:**
1. Получить шаблон от администратора
2. Заполнить планы по своим магазинам
3. Отправить файл администратору

### **Для разработчика:**
1. Добавить новые показатели в лист "Настройки"
2. Обновить соответствующие столбцы в "Цели"
3. Протестировать импорт

## ⚠️ Ограничения и рекомендации

### **Технические ограничения:**
- Максимальный размер файла: 10 МБ
- Поддерживаемые форматы: `.xlsx`, `.xls`
- Максимум показателей: 50
- Значения должны быть числовыми (0.0-1.0)

### **Рекомендации:**
- Всегда используйте свежий шаблон
- Тестируйте на небольших данных
- Делайте резервные копии перед импортом
- Проверяйте консоль браузера при ошибках
