# 📊 COM - Odoo Аддон с Vue.js Интеграцией

Полноценная интеграция Vue.js 3 с Odoo 18 для аналитики продаж и управления планами - **РАБОЧАЯ ВЕРСИЯ** ✅

## 🎉 Статус: ГОТОВ К ИСПОЛЬЗОВАНИЮ

Этот модуль **сразу работает** после установки! Основной компонент **Dashboard.vue** предоставляет полнофункциональную аналитику продаж с поддержкой импорта данных из Excel.

---

## 🚀 Быстрый старт

### 1. Установка в Odoo
```bash
# Скопируйте модуль в addons
cp -r com /path/to/odoo/addons/

# В Odoo: Apps → Update Apps List → Install "com"
```

### 2. Откройте аналитику
- Откройте меню **SMK Analytics** в Odoo
- Начните с "Аналитика продаж" - полнофункциональный дашборд
- Перейдите в "Настройки планов" для редактирования

### 3. Настройка полного Vue.js (опционально)
```bash
cd com/static/
npm install
npm run build-watch
```

## 🔌 Техническая архитектура

### Backend API (готово к расширению):
- `POST /vue/api/data` - универсальное получение данных
- `POST /vue/api/create` - создание записей в Odoo
- `POST /vue/api/update` - обновление записей
- `POST /vue/api/delete` - удаление записей
- `POST /vue/api/user-info` - информация о пользователе

### Frontend (готово к развертыванию):
- Vue.js 3 с Composition API
- Vue Router для навигации
- **SheetJS (xlsx)** - обработка Excel файлов
- localStorage вместо Pinia (проще и надежнее)
- Адаптивный дизайн для мобильных

## ❓ Частые вопросы

**Q: Не работает после установки?**
A: Проверьте консоль браузера, обновите модуль в Odoo

**Q: Как редактировать планы массово?**  
A: Используйте Excel импорт: "📥 Шаблон Excel" → редактирование → "📤 Завантажити Excel"

**Q: Какие форматы Excel поддерживаются?**
A: `.xlsx` (Excel 2007+) и `.xls` (Excel 97-2003)

**Q: Что делать при ошибке валидации Excel?**
A: Скачайте свежий шаблон и проверьте структуру данных. Подробности в [EXCEL_IMPORT_GUIDE.md](EXCEL_IMPORT_GUIDE.md)

**Q: Можно ли экспортировать настройки?**
A: Да, в "Настройки планов" есть полный функционал экспорта/импорта через Excel
